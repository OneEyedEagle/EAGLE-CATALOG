### 2022

#### 2022.8 · 美梦图书馆

![](images/sig_game_dream_library.jpg)

| 游戏类型 | 剧情标签 | 简介 |
| :--- | :--- | :--- |
| AVG | 温馨 / 欢乐 | 本馆收藏各类人生图书，提供免费编辑功能，帮助您放下心中执念，早日开启来生。 |

**制作感想**  
起初看到这一次极短的主题时，觉得真的太难了，完全想不到怎么把这个东西展现在游戏中。然后在tb上买书时忽然想到，每本书（特指那种鸡汤书）的大章节前都有前情提要，说明一下上一章讲了什么，这一章会继续讲什么。那如果把这种用在人生上呢？但是单独的查看会很无聊，那如果可以编辑呢？但是编辑可能出现太多蝴蝶效应，那如果只是单纯的虚假覆盖，用来消解执念？就这样一步步创作完成了整个大纲。而在具体的每本书上，参考了各种wb的新闻，毕竟魔幻现实，素材真的太多力。最后还要感谢突然主动愿意提供图块的深草聚聚，不然图书馆就真的太破旧了呜呜呜。
